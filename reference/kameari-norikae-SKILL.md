# 亀有の乗換案内（取り込み済みダイヤ）

返事は関西弁、結論から。まず今日の曜日と時刻を確かめて、平日か土休日かを決める。

## 決まりごと
- 行き：亀有から常磐線各駅停車（千代田線直通）に乗り、綾瀬で「JRから来る電車以外」＝綾瀬始発か北綾瀬始発に乗り換える。綾瀬で乗れるのは「亀有発車＋4分以降」に綾瀬を出る始発。
- 帰り：品川始発の常磐線（上野東京ライン）に座る。
  - ①北千住乗り換え：千代田線のうち我孫子・取手・柏・松戸行きだけが亀有に止まる（綾瀬行き・北綾瀬行きは止まらない）。乗り換え1分。
  - ②松戸折り返し：松戸で各駅停車の上り（6番線、綾瀬・代々木上原方面）に乗る。乗り換え1分。亀有で松戸経由を申し出て精算。
- 亀有の時刻は時刻表上の発車時刻。着くのはその数十秒前。
- 表の時刻は時刻表どおり。遅れは反映していない。1分ちょうどの乗り換えは「ギリギリ」と添える。

## 乗る位置（出典：わだっつログ。現地確認はしていない）
- 北千住：品川からの常磐線は1番線に着く。グリーン車付きの電車は5号車（グリーン車）の進行方向2番目のドア（5号車1番ドア）の前の階段が千代田線への近道。普通車に乗るなら、その隣の6号車のいちばん後ろあたり（目安・未確認）。千代田線は2番線（綾瀬方面）。
- 松戸：品川からの常磐線は1番線に着く（特急待ちのときは2番線）。各駅停車の上りは6番線。
  - 1番線（15両）の上り階段：10号車前（アトレ北口方面）、8号車前（同）、7号車後ろ（中央改札方面・エスカレーターあり）、4号車前。
  - 6番線の階段：9号車の前から2番目のドア付近（アトレ北口方面）、5号車の先頭ドア付近（中央改札方面・エスカレーターあり）、7号車の2・3番目のドア付近。
  - 中央改札方面のルートが速い（夏目さん確認済み）：7号車の後ろのドアで降りる（エスカレーターあり）→6番線は5号車の先頭ドア付近に出る。

## 土休日・確認用の資料（最新版のURL）
土休日は帰りだけ取り込み済み。行きと、取り込み直しのときは下のページを使う。JR東日本の時刻表は版（例：2610）ごとにURLが変わるので、まず一覧ページから入る。
- 品川駅一覧 https://timetables.jreast.co.jp/timetable/list0788.html （上野東京ライン(常磐線)の平日・土休日。各時刻から停車駅一覧に入れる＝北千住・松戸の着発がわかる）
- 松戸駅一覧 https://timetables.jreast.co.jp/timetable/list1441.html （常磐線各駅停車 綾瀬方面、各路線の縦の時刻表への入口）
- 縦の時刻表：常磐線快速下り 642d1(平日)/642d2(土休日)、千代田線・常磐線各停 下り 641d1/641d2、上り 641u1/641u2（https://timetables.jreast.co.jp/2610/timetable-v/…html）
- 綾瀬の全列車：駅探 https://ekitan.com/timetable/railway/line-station/276-1/d2 （列車リンクの tx が「A」で始まるのがJRから来る電車。それ以外が綾瀬始発・北綾瀬始発）
- 北千住の千代田線行先：駅探 https://ekitan.com/timetable/railway/line-station/276-2/d1
- 乗る位置：わだっつログ（北千住の常磐線→千代田線乗換、松戸駅の停車位置）
